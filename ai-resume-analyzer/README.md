# AI Resume Analyzer & Job Matcher

AI-powered web application that analyzes resumes against job descriptions
and provides match scores, missing skills, and improvement summaries.

## Features
- Resume and job description comparison using OpenAI
- AI-generated match score and feedback
- Clean, responsive UI
- RESTful API architecture

## Tech Stack
Next.js, React, OpenAI, Material UI

## How to Run
```bash
npm install
npm run dev
