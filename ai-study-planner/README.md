# AI Study Planner & Question Generator

AI-powered web application that generates personalized study plans
and practice questions based on user goals and deadlines.

## Features
- AI-generated study schedules
- Daily learning tasks and practice questions
- Clean, intuitive UI
- RESTful API design

## Tech Stack
Next.js, React, OpenAI, Material UI
